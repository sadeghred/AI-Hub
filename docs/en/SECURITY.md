# Security

The public repository must never contain provider API keys, bot tokens, passwords, authentication secrets, private server credentials, production database credentials, real environment files, private keys, credential-vault contents, production backups, or deployable private source archives.

Client applications should not require direct provider credentials. Provider credentials remain centrally controlled by AI-Hub.

Before every public update, documentation and screenshots should be reviewed for secrets, IP addresses, connection strings, copied production logs, and other sensitive operational data.
