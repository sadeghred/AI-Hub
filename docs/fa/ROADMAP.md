# نقشه راه

این Roadmap جهت کلی پروژه را نشان می‌دهد و تعهد زمانی انتشار نیست.

## زیرساخت فعلی
- Central AI Gateway
- Async Worker مستقل
- Administration Service مستقل
- Routing مرکزی Provider/Model
- جداسازی Credential
- معماری Fallback/Rotation
- State مرکزی مبتنی بر PostgreSQL
- مدیریت سرویس‌های Linux
- Integration عملی با Tel-News

## مراحل بعدی
- تکمیل مستندات عمومی صفحه‌به‌صفحه
- اضافه‌کردن Diagramهای Sanitized
- مستندسازی قرارداد Taskها
- توسعه مستندات Health/Status و Observability
- افزودن مثال‌های Synthetic برای Clientها
- افزودن Screenshotهای بررسی‌شده
- اضافه‌کردن Integrationهای پایدار جدید
